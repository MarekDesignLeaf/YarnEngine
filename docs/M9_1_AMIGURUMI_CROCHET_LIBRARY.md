# M9.1 Amigurumi Crochet Library

M9.1 adds crochet/amigurumi support based on standard crochet operations and internally authored reference structures.

Canonical crochet operations include chain, slip stitch, single crochet, half double crochet, double crochet, treble, double treble, common decreases, explicit increases, front/back loop variants, front/back post double crochet, puff and popcorn.

The bundled fixed-repeat library adds 47 crochet reference patterns focused on dense single-crochet toy fabric, FLO/BLO variants, basic taller stitches and texture references.

Variable stitch-count amigurumi shaping is represented separately by the round engine. This avoids falsely encoding increases and decreases as fixed-width repeating fabric patterns.

Evidence boundary:
Operation names and standardized stitch concepts are based on Craft Yarn Council crochet standards. The 47 pattern records are internal reference structures, not copied third-party patterns. No yarn-consumption coefficient is assigned to crochet operations. Crochet consumption requires crochet-specific calibration data before production accuracy can be claimed.
