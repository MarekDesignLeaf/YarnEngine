# M9.2 Complex Construction Consumption Bridge

M9.2 connects executable branch knitting and amigurumi round programs to the calibrated consumption model.

The authoritative input is the aggregated count of canonical operations actually executed by the program. A rectangular repeat area is not used to manufacture operation counts for these shaped constructions.

Supported program sources:
* branch
* amigurumi

The bridge requires an approved production calibration model and applies the M8 strict/warn/research domain policy. If crochet operations are absent from the approved model domain, strict mode rejects the calculation.

This means crochet/amigurumi can now travel through the same audited consumption pipeline, but M9.2 does not invent crochet coefficients. A knitting-only production model cannot truthfully provide production crochet consumption merely because the software understands SC or SC2TOG structurally.
