# M10.0 Completion Baseline

M10.0 closes the remaining software architecture gap explicitly identified by the original Master advanced-library direction: multi-yarn/colourwork routing and multi-part project aggregation.

Multi-yarn:
Canonical operations can be assigned to explicit yarn carriers. Consumption is aggregated per yarn. Explicit float lengths can be added. The engine does not invent a colourwork float coefficient. The API requires an already governed prediction for each yarn and verifies operation-count agreement.

Toy assembly:
Parts such as body, head, limbs, ears, wings and tails can be aggregated into a per-yarn bill of materials. Sewing, embroidery and decorative yarn are included only when explicitly supplied or measured.

Important release boundary:
The software architecture is now substantially beyond Master v0.1, but production crochet accuracy remains launch-gated by real physical calibration data. The original Master also targeted 500+ patterns at the advanced scale; the bundled library remains 174 patterns. This is a content/data scale target, not a missing calculation architecture.

No fabricated production coefficients or physical measurements were introduced.
